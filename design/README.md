# Lautta UI/UX design

Silica mockups, one per screen, kept as Design canvas.

- `canvas/project/canvas.json`: board layout, rows by area (browse, directory, states and errors, file operations, transfers, preview, search, settings, landscape, menus).
- `canvas/project/*.dc.html`: one artboard per screen or state, 400×860 portrait (860×400 landscape); `ambience` tweak dark/light.
- `STYLE.md`: Silica style kit all boards share.
