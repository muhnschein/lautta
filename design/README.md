# Lautta UI/UX design

Silica (Sailfish OS) mockups for every feature in the Lautta spec, kept as a Design canvas.

- `canvas/project/canvas.json`: board layout (rows: Browse & locations, Directory, States & errors, File operations, Transfers & system surfaces, Preview/open/edit, Search & sync, Settings & about, Landscape, Menus & remaining moments).
- `canvas/project/*.dc.html`: one artboard per screen/state, 400×860 portrait (860×400 landscape). Each has an `ambience` tweak (dark/light).
- `STYLE.md`: the Silica style kit all boards share (Theme sizes, colours, components, icons, and the iOS/Android patterns to avoid).
