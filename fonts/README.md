# Bundled fonts

`JetBrainsMono-Regular.ttf`: JetBrains Mono 2.304, unmodified, from
https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304. SIL Open Font License 1.1:
`OFL.txt`. Ships in `/usr/share/harbour-lautta/fonts/`; family name in
`lautta_core::fonts::MONO_FAMILY`.

Regular only: monospace text never asks for other weights; bold, if ever, is synthesised.
